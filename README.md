# Filee (versão enxuta) — releases

Canal de atualização automática da versão enxuta do Filee. Aqui ficam só os instaladores
(`Filee-X.Y.Z-win-Setup.exe`) e os arquivos `SHA256SUMS`; o código-fonte é privado.

Baseado no [Filee](https://github.com/KnifeLemon/Filee) de Myeonggu Kim (KnifeLemon) e colaboradores,
licença MIT (veja `LICENSE`). Esta versão acrescenta o motor SHD/SHM das texturas do Thang Online e
ajustes de desempenho, e se atualiza a partir deste repositório, não do Filee oficial.
